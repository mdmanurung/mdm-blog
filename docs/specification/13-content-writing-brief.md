# 13 — Copywriting brief and content collection

## Positioning

Aim for a 20–30 word professional summary that unifies population immunology, infection/vaccine responses and computational biology. Subject to owner review, a **draft** positioning is:

> I study how human immune responses vary across populations and use experimental and computational methods to investigate the roles of genetics, environment and infection history.

Avoid using an unverified current affiliation, claimed lead role, grant title, or unsupported outcomes. Academic identity can precede institutional affiliation.

## Homepage content slots

- H1: question-driven scientific identity; no motivational slogan.
- Subheading: what is investigated; relevant populations; methods, in readable language.
- `Research` CTA and second CTA (`Publications` or `CV`).
- Theme teasers: each begins with a research question, not list of buzzwords.
- Featured papers: `what was asked` / `what was found` / `why it matters`; requires DOI evidence and owner approval.
- Software: `What scientific problem does this solve?` / `What should a first-time user click?`
- Writing: essay type + original platform label.

## About (3 concise paragraphs)

1. Scientific questions and disciplinary training.
2. Experimental/computational approach and international cohort experience, with no sensitive participant details.
3. Present/current appointment (date-checked), collaboration interests, professional contact.

Timeline should distinguish confirmed future role from a current appointment. Use source-backed academic positions and accurate dates.

## Publication metadata editorial guide

Titles/authors/venues should reflect published bibliographic metadata. Only owner-authored 1-line lay significance should use interpretive language. Distinguish **preprint**, **accepted**, **peer-reviewed**, and **in preparation**; in-preparation work normally does not belong in publications directory.

## Scientific software metadata editorial guide

Avoid advertising every code repository. Group by user purpose e.g. `single-cell analysis`, `statistical methods`, `viral detection`, `reproducible workflows`. For all featured repos, supply documentation and candid maturity labels. Do not infer code stability from GitHub activity alone.

## Required owner-verified factual inputs

- Current short bio and whether to announce future postdoctoral role at Sanger as of the launch date.
- Official ORCID, personal domain preference, CV PDF, public contact address.
- Verified Substack feed or custom domain; whether links should target Substack only.
- Approved 3 featured papers with DOIs and 3–4 featured tools with repo links.
- Consent/license for profile photo, figure thumbnails and logos.

## Editorial rhythm

Monthly: short post or news update if substantive. Quarterly: review featured publications/software and bio, broken links and content provenance. Avoid a 'Latest updates' section that becomes visibly stale; scientific work need not generate weekly novelty.
